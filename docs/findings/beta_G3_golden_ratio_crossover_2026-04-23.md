### 1.2 精确交叉点

交叉点（log_neg = Pirandola）在数值上**精确等于黄金比例的倒数**：

$$\boxed{\eta_c = \frac{1}{\varphi} = \varphi - 1 = \frac{\sqrt{5}-1}{2} \approx 0.6180}$$

其中 φ = (1+√5)/2 ≈ 1.6180 是黄金比例。

### 1.3 交叉点处的精确值

在 η_c = 1/φ 处：

$$\text{log\_neg}(\mathcal{E}_1 \otimes \mathcal{E}_2)|_{\eta=1/\varphi} = \text{Pirandola}(1/\varphi) = 2\log_2\varphi \approx 1.3885 \text{ bits}$$

验证：
- Pirandola(η=1/φ) = -log₂(1-1/φ) = -log₂(1/φ²) = 2log₂(φ) ✓（因为 1-1/φ = 1/φ²）
- 单臂 log_neg(E₁)|_{η=1/φ} = log₂(φ) 精确成立（数值验证 ratio = 1.000000）

## 2. 解析结构 [CONJ-DRAFT]

### 2.1 黄金比例与幅度阻尼

**[CONJ-DRAFT]** 幅度阻尼信道 E_AD 在 η = 1/φ 时的 Choi 态偏转置的迹范数恰为 φ：

$$\|\rho_\text{Choi}^{T_2}\|_1 = \varphi \quad \text{at } \eta = 1/\varphi \quad \text{[CONJ-DRAFT]}$$

这直接给出 log_neg(E₁) = log₂(φ)，从而 log_neg(E₁⊗E₂) = 2log₂(φ) = Pirandola(1/φ)。

**推导方向**（用户验证）：

Choi 态偏转置的负特征值为（对 2×2 块）：
$$\lambda_- = \frac{1-\eta}{4} - \sqrt{\frac{(1-\eta)^2}{16} + \frac{\eta}{4}}$$

迹范数：$\|\rho^{T_2}\|_1 = 1 + 2|\lambda_-|$

在 η = 1/φ（即 1-η = 1/φ²）时，若可验证 $\|\rho^{T_2}\|_1 = \varphi$，则以上关系成立。

**黄金比例性质** (验证辅助)：
- φ² = φ + 1
- 1/φ = φ - 1
- 1/φ² = 1 - 1/φ = 2 - φ

### 2.2 为什么黄金比例出现？

**数值猜想 [CONJ-DRAFT]**：幅度阻尼信道的对数负性是 η 的函数，在 η = 1/φ 时它与 -log₂(1-η) 相等。这一交叉点由方程 f(η) = g(η) 确定，其中两条曲线的斜率关系可能引入黄金比例的不动点特性（φ² = φ + 1）。

## 3. 对 β 路径的意义

### 3.1 物理解读

- **η > η_c ≈ 0.618**（高透射区）：log_neg(E₁⊗E₂) < Pirandola
  - E_R ≤ log_neg < Pirandola → β 路径上界**严格比 Pirandola 更紧**（若 E_R 可作为 umr 上界）
  - 但需 β.G4 + β.G5 结构性 gaps 闭合
  
- **η < η_c ≈ 0.618**（低透射区，实用 QKD 范围）：log_neg(E₁⊗E₂) > Pirandola
  - 仅凭 log_neg proxy 无法得出 β 更紧的结论
  - 直接 E_R SDP（非 log_neg proxy）可能仍更紧（E_R ≤ log_neg）

### 3.2 实用 QKD 的典型 η 范围

大多数光纤 QKD 在：
- 10 dB 链路损耗：η ≈ 0.1 × 0.1 = 0.01（end-to-end，每臂 0.1）
- 5 dB 链路损耗：η_arm ≈ 0.316

**对于 log_neg proxy**：两者都远低于 η_c = 0.618，log_neg > Pirandola，不能给出更紧的上界。

**对于 E_R^PPT（若加性）**：在所有 η 范围内 E_R^PPT < Pirandola。实用 QKD 范围内：
- η_arm=0.1：2×E_R^PPT ≈ 0.123 vs Pirandola = 0.152，比 Pirandola 紧约 19%
- η_arm=0.01：2×E_R^PPT ≈ 0.013 vs Pirandola = 0.0145，比 Pirandola 紧约 10%

### 3.3 直接 E_R SDP 的潜力

即使 η < η_c，直接 E_R SDP（非 log_neg 代理）可能仍给出更紧的值，因为：
- E_R(M̃) ≤ E_R(E₁⊗E₂) ≤ log_neg(E₁⊗E₂)
- 不等式可以严格，特别是在 Charlie BSM LOCC 后

但 `e_r_channel_ppt` dim_A=4 在当前计算能力下超时（>60s/点），需要更高效的实现或用户环境。

## 4. 与 γ 路径的对比

| 指标 | β 路径（qubit 数值）| γ 路径（bosonic 精确）|
|------|--------------------|-----------------------|
| 上界公式 | E_R^PPT(M̃) [SDP] | -log₂(1-η_arm) [PLOB exact] |
| 对 η<η_c 的比较 | log_neg > Pirandola（proxy 不更紧）| 单臂 = Pirandola（精确相等，Alice-Charlie only）|
| 是否有 umr 形式化 | β.G4+G5 结构 OPEN | γ.B chain 结构 OPEN |

γ 路径的目标值（-log₂(1-η_arm)）正好是 Pirandola 对称情形的精确值。而 β 路径的 log_neg 在 η > η_c 时更紧。这意味着：
- **若 β.G5 能闭合**：β 可能在 η > η_c 给出更紧的 [COROLLARY]
- **若 γ.B 能闭合**：γ 给出与 Pirandola 相等的 [COROLLARY]（即 Pirandola 在 umr 下紧）
