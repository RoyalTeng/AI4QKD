### 1.2 精确交叉点

交叉点（log_neg = Pirandola）在数值上**精确等于黄金比例的倒数**：

$$\boxed{\eta_c = \frac{1}{\varphi} = \varphi - 1 = \frac{\sqrt{5}-1}{2} \approx 0.6180}$$

其中 φ = (1+√5)/2 ≈ 1.6180 是黄金比例。

### 1.3 交叉点处的精确值

在 η_c = 1/φ 处：

$$\text{log\_neg}(\mathcal{E}_1 \otimes \mathcal{E}_2)|_{\eta=1/\varphi} = \text{Pirandola}(1/\varphi) = 2\log_2\varphi \approx 1.3885 \text{ bits}$$

验证：
- Pirandola(η=1/φ) = -log₂(1-1/φ) = -log₂(1/φ²) = 2log₂(φ) ✓（因为 1-1/φ = 1/φ²）
- 单臂 log_neg(E₁)|_{η=1/φ} = log₂(φ) 精确成立（数值验证 ratio = 1.000000）

## 2. 解析推导 [SYN，用户纸笔复核可升至 COROLLARY]

### 2.1 精确公式：log_neg(E_AD(η)) = log₂(1+η)（所有 η）

**数值验证**（7 个点，最大误差 6.66e-16 = 机器精度）：

| η | ||ρ^{T_B}||₁ | 1+η | 误差 |
|---|-------------|-----|------|
| 0.10 | 1.1000000000 | 1.1 | 4.44e-16 |
| 0.50 | 1.5000000000 | 1.5 | 2.22e-16 |
| **1/φ** | **1.6180339887** | **φ** | 4.44e-16 |
| 0.90 | 1.9000000000 | 1.9 | 4.44e-16 |

**解析推导候选** [SYN，待用户纸笔复核]：

1. **Choi 态**（归一化，基 {|00⟩,|01⟩,|10⟩,|11⟩}）：

$$\rho_{AD}(\eta) = \frac{1}{2}\begin{pmatrix}1&0&0&\sqrt\eta\\0&0&0&0\\0&0&1-\eta&0\\\sqrt\eta&0&0&\eta\end{pmatrix}$$

2. **偏转置** T_B（对 B 子系统）：$\rho^{T_B}_{(i,j),(k,l)} = \rho_{(i,l),(k,j)}$

$$\rho^{T_B} = \frac{1}{2}\begin{pmatrix}1&0&0&0\\0&0&\sqrt\eta&0\\0&\sqrt\eta&1-\eta&0\\0&0&0&\eta\end{pmatrix}$$

块对角结构：
- 块 A（{|00⟩,|11⟩}）：$\text{diag}(1/2, \eta/2)$，特征值均正
- 块 B（{|01⟩,|10⟩}）：$\begin{pmatrix}0&\sqrt\eta/2\\\sqrt\eta/2&(1-\eta)/2\end{pmatrix}$

3. **块 B 特征值**（解 λ² - λ(1-η)/2 - η/4 = 0）：

$$\Delta = \frac{(1-\eta)^2}{4} + \eta = \frac{(1+\eta)^2}{4}$$
$$\lambda_{\pm} = \frac{(1-\eta) \pm (1+\eta)}{4} \implies \lambda_+ = \frac{1}{2},\quad \lambda_- = -\frac{\eta}{2}$$

4. **迹范数**（4 个特征值 {1/2, η/2, 1/2, -η/2}）：

$$\|\rho^{T_B}\|_1 = \frac{1}{2} + \frac{\eta}{2} + \frac{1}{2} + \frac{\eta}{2} = 1 + \eta$$

5. **对数负性**：

$$\boxed{\log\text{-neg}(\mathcal{E}_{AD}(\eta)) = \log_2(1+\eta) \text{ for all } \eta \in [0,1]}$$

**用户验证**：可用 5 分钟纸笔验证步骤 1-5。升级为 [COROLLARY] 需 C1+C2+C3（R0.2）。

### 2.2 黄金比例出现的精确原因

交叉点方程：$2\log_2(1+\eta) = -\log_2(1-\eta)$，即：

$$(1+\eta)^2(1-\eta) = 1$$

展开：$(1+\eta)^2(1-\eta) = 1 + \eta - \eta^2 - \eta^3 = 1$

$$\Rightarrow \eta(1 - \eta - \eta^2) = 0$$

解：$\eta = 0$（**平凡边界解**，两界均为 0）或 $\eta^2 + \eta - 1 = 0$（**非平凡内点解**）。

在 $(0,1)$ 内取正根：

$$\eta_c = \frac{-1+\sqrt{5}}{2} = \frac{1}{\varphi} \approx 0.6180 \quad \blacksquare$$

**物理意义**：黄金比例出现因为 $1/\varphi$ 满足 $1/\varphi^2 + 1/\varphi = 1$（即 $\eta^2+\eta=1$），这正是 $(1+\eta)^2=1/(1-\eta)$ 的非平凡正实数解。$\eta=0$ 是平凡解（两界均为零），不是物理上感兴趣的交叉点。

## 3. 对 β 路径的意义

### 3.1 物理解读

- **η > η_c ≈ 0.618**（高透射区）：log_neg(E₁⊗E₂) < Pirandola
  - E_R ≤ log_neg < Pirandola → β 路径上界**严格比 Pirandola 更紧**（若 E_R 可作为 umr 上界）
  - 但需 β.G4 + β.G5 结构性 gaps 闭合
  
- **η < η_c ≈ 0.618**（低透射区，实用 QKD 范围）：log_neg(E₁⊗E₂) > Pirandola
  - 仅凭 log_neg proxy 无法得出 β 更紧的结论
  - 直接 E_R SDP（非 log_neg proxy）可能仍更紧（E_R ≤ log_neg）

### 3.2 实用 QKD 的典型 η 范围

大多数光纤 QKD 在：
- 10 dB 链路损耗：η ≈ 0.1 × 0.1 = 0.01（end-to-end，每臂 0.1）
- 5 dB 链路损耗：η_arm ≈ 0.316

**对于 log_neg proxy**：两者都远低于 η_c = 0.618，log_neg > Pirandola，不能给出更紧的上界。

**对于 E_R^PPT（若加性）**：在所有 η 范围内 E_R^PPT < Pirandola。实用 QKD 范围内：
- η_arm=0.1：2×E_R^PPT ≈ 0.123 vs Pirandola = 0.152，比 Pirandola 紧约 19%
- η_arm=0.01：2×E_R^PPT ≈ 0.013 vs Pirandola = 0.0145，比 Pirandola 紧约 10%

### 3.3 直接 E_R SDP 的潜力

即使 η < η_c，直接 E_R SDP（非 log_neg 代理）可能仍给出更紧的值，因为：
- E_R(M̃) ≤ E_R(E₁⊗E₂) ≤ log_neg(E₁⊗E₂)
- 不等式可以严格，特别是在 Charlie BSM LOCC 后

但 `e_r_channel_ppt` dim_A=4 在当前计算能力下超时（>60s/点），需要更高效的实现或用户环境。

## 4. 与 γ 路径的对比

| 指标 | β 路径（qubit 数值）| γ 路径（bosonic 精确）|
|------|--------------------|-----------------------|
| 上界公式 | E_R^PPT(M̃) [SDP] | -log₂(1-η_arm) [PLOB exact] |
| 对 η<η_c 的比较 | log_neg > Pirandola（proxy 不更紧）| 单臂 = Pirandola（精确相等，Alice-Charlie only）|
| 是否有 umr 形式化 | β.G4+G5 结构 OPEN | γ.B chain 结构 OPEN |

γ 路径的目标值（-log₂(1-η_arm)）正好是 Pirandola 对称情形的精确值。而 β 路径的 log_neg 在 η > η_c 时更紧。这意味着：
- **若 β.G5 能闭合**：β 可能在 η > η_c 给出更紧的 [COROLLARY]
- **若 γ.B 能闭合**：γ 给出与 Pirandola 相等的 [COROLLARY]（即 Pirandola 在 umr 下紧）
