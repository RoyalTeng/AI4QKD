### 3.3 [FIND] η_d=0.5 单项效应精确匹配 plan 20-50% 上端(50.0-51.4%)

**观察**:仅 η_d=0.5 引入(其他器件参数保持理想,p_d=0, e_d=0),实测退化率在所有距离 **50.0-51.4 %**,**精确落在 plan §3.2 S2.3 预期的 20-50% 范围上端(略超 1-2 pp)**。

**解释**:η_d=0.5 使 Y_1 ≈ η·μ·e^{-μ} 的 η 因子直接减半,在 GLLP 框架中 Q_1^L ≈ 0.5·Q_1^{ideal},privacy 项 ∝ Q_1^L,故 key rate 约降为 50%。

**结论**:plan §3.2 S2.3 的 "20-50% 退化" 估计在 **η_d 作为唯一缺陷** 的解读下,**准确**(实测 50.0-51.4%,仅略超上端)。

### 3.4 [FIND] Misalignment e_d=0.033 引入额外 ~34 pp 退化(远超 dark count 贡献)

**三项缺陷的增量贡献**(叠加顺序 η_d → +misalign → +dark count):

| L(km) | η_d → 50% | +misalign → 84% | +p_d → 85% |
|------:|-----------:|-----------------:|------------:|
|   0.0 | +51.4 | +31.9 | 0.0 |
|  25.0 | +50.7 | +33.5 | 0.0 |
|  50.0 | +50.2 | +34.2 | 0.0 |
| 100.0 | +50.0 | +34.4 | +0.3 |
| 150.0 | +50.0 | +34.5 | +2.9 |

**观察**:
- **η_d**:50-51% 恒定,等比缩放
- **misalignment e_d=0.033**:额外 31.9-34.5 pp,随距离微增
- **dark count p_d=1e-6**:< 0.3 pp 至 100 km;150 km 升到 2.9 pp(长距离 Y_1 逼近 Y_0 时主导)

**结论**:plan §3.2 S2.3 的 "20-50% 退化" 估计**不包含** e_d=0.033 的 misalignment 效应。若 plan 的"典型参数"语义默认 e_d=0,则实测完全符合;若"典型参数"含 e_d=0.033(本实验采用),实测退化 **83-87%**,主要由 misalignment 主导。

## 4. 对 plan 的 finding summary(不含修订建议)

1. Plan §3.2 S2.3 的 "20-50% 退化" 预期在 **η_d 单独效应** 口径下**实测验证**(50.0-51.4%,略超上端)
2. Plan 未明示 "典型参数" 是否含 misalignment;实测若含 e_d=0.033,总退化 83-87%(超出 plan 列出的 20-50% 但这是 scope 差异,非 plan 数值错误)
3. Dark count p_d=1e-6 在 100 km 以内贡献 <0.3 pp,**至 150 km 可达 2.9 pp**(长距离 Y_0 主导)
4. LMC_2005_FIG3 档位(η_d=0.145 + e_d=0.033 + p_d=8.5e-7)退化率 95-97%,与 1-decoy 对极低 η_d 敏感一致

## 5. Limitations

1. **1-decoy only**:未对比 2-decoy(Phase 0 `decoy_wlc_rate_two` 已实现),2-decoy 的 Y_1^L 更紧可能改变 IDEAL/TYPICAL 比值
2. **固定 f_ec=1.22**:未扫描 f_ec 灵敏度
3. **Asymptotic 无限密钥**:无 finite-size 修正,由 S2.4-S2.5 GEAT 承接
4. **Misalignment 建模**:`FibreChannel.e_misalignment = 0.033` 是与光子数无关的 bit-flip 常数(Ma 2005 Eq. 17 约定);真实系统可能有 photon-number 相关漂移,本模型不 covered
5. **Detector symmetry**:假设两 detector 相同;asymmetric detector 不 covered
6. **Joint (distance, μ, ν) 未联合优化**:本实验固定 ν = 0.2·μ,未独立优化 ν。完全 joint 优化可能在 ν ≠ 0.2μ 处给出略微更高 rate(预期 <5% 改进,基于 Ma 2005 §V μ-ν insensitivity)
7. **PDC / Fock state source**:本实验仅 coherent state decoy;PDC 单光子源模型不 covered(属于 decoy-free 路径,scope 外)
8. **2-D 扫描精度**:1221-point 2-D 扫描精度 distance 5 km × μ 0.025;Pareto envelope 精细细化未做

## 6. 复现

核心表 3.1 重跑命令:

```python
from qkdx.sweeps.decoy_bb84_sweep import (
    DeviceProfile, IDEAL, TYPICAL_S23, LMC_2005_FIG3,
    sweep_decoy_bb84_mu_distance,
)
import numpy as np

ETA_D_ONLY = DeviceProfile(
    name="+eta_d=0.5_only", eta_detector=0.5, p_dark=0.0, e_misalignment=0.0,
)
ETA_D_PLUS_MISALIGN = DeviceProfile(
    name="+eta_d=0.5+e_d=0.033",
    eta_detector=0.5, p_dark=0.0, e_misalignment=0.033,
)

for profile in [IDEAL, ETA_D_ONLY, ETA_D_PLUS_MISALIGN, TYPICAL_S23, LMC_2005_FIG3]:
    mus = np.linspace(0.1, 0.9, 41)
    for L in [0, 25, 50, 75, 100, 150]:
        pts = sweep_decoy_bb84_mu_distance(profile, [L], mus, nu_ratio=0.2)
        rates = [p.objectives[0] for p in pts]
        best = max(0.0, max(rates))
        print(f"{profile.name:<25} L={L:<5} best={best:.6f}")
```
