## 1. 一句话总结

**TGW 2014 是首个 single-letter 上界对 point-to-point QKD 的 two-way assisted private capacity**,用 **squashed entanglement of a channel** $E_\text{sq}(\mathcal{N}) := \max_{|\phi\rangle} E_\text{sq}(A;B)_\rho$ 作为工具,证明 $P_2(\mathcal{N}) \leq E_\text{sq}(\mathcal{N})$;对 pure-loss channel 给出 $P_2(N_\eta) \leq \log_2[(1+\eta)/(1-\eta)]$,高损极限 $\lesssim 2.88\eta$ bits/mode。PLOB 2017 后来超越(1.44η,2× 更紧),但 TGW 的 squashed-E 技术对 non-distillable / non-Gaussian 信道(如 amplitude damping)可能仍提供更紧上界。

## 3. 数学准备

### 3.1 Squashed entanglement(Christandl-Winter 2004,Tucci 1999)

对 bipartite state $\rho_{AB}$,squashed entanglement 定义为:
$$E_\text{sq}(A;B)_\rho := \frac{1}{2} \inf_{\mathcal{S}_{E\to E'}} I(A;B|E')_{\rho_{ABE'}}$$

其中 inf 取遍所有 "squashing channel" $\mathcal{S}$ from purifying system $E$ to $E'$.

**关键性质**:
1. **Entanglement monotone under LOCC**:$E_\text{sq}(\Lambda(\rho)) \leq E_\text{sq}(\rho)$ for any LOCC Λ
2. **Normalization on private states**:$E_\text{sq}(\gamma)_γ \geq \log_2 d$ for d-bit private state(Proposition 4.19 of Christandl thesis)
3. **Continuity inequality(Eq. 5)**:
   $$|E_\text{sq}(A;B)_\rho - E_\text{sq}(A;B)_\sigma| \leq 16\sqrt{\varepsilon} \log d' + 4 h_2(2\sqrt{\varepsilon})$$
   when $\|\rho_{AB} - \sigma_{AB}\|_1 \leq \varepsilon$,with $d' = \min\{|A|, |B|\}$
4. **Convexity**: $E_\text{sq}$ is convex in its argument
5. **All 8 axioms of entanglement measures**(唯一已知满足所有的 measure)
6. **Subadditivity**(TGW Lemma 2, 新贡献):对 5-party pure state $\psi_{AB_1E_1B_2E_2}$,
   $$E_\text{sq}(A; B_1B_2)_\psi \leq E_\text{sq}(AB_2E_2; B_1)_\psi + E_\text{sq}(AB_1E_1; B_2)_\psi$$

### 3.2 Squashed entanglement of a channel(TGW 贡献)

对 channel $\mathcal{N}_{A' \to B}$,squashed entanglement 扩展为:
$$E_\text{sq}(\mathcal{N}) := \max_{|\phi\rangle_{AA'}} E_\text{sq}(A;B)_\rho, \quad \rho_{AB} = \mathcal{N}_{A' \to B}(|\phi\rangle\langle\phi|)$$

max 取 pure bipartite input(due to convexity of $E_\text{sq}$,不需要 mixed inputs);input space compact + $E_\text{sq}$ continuous → 可以用 max 替代 sup.

## 4. 主定理

### 4.1 Theorem 1 — 单字母上界

**对任意 quantum channel $\mathcal{N}$**:
$$P_2(\mathcal{N}) \leq E_\text{sq}(\mathcal{N})$$

其中 $P_2(\mathcal{N})$ 是 $\mathcal{N}$ 的 two-way assisted private capacity.

**物理意义**:无论协议采用多少 channel uses n 与多么复杂的 LOPC 策略,单次 channel use 的 $E_\text{sq}$ 已给出 ultimate rate bound(single-letter form)。

### 4.2 证明 Sketch(§Results Theorem 1 proof)

**Structure**:
1. 任意 $(n, R, \varepsilon)$ 协议输出 state $\omega_{ABE_1\cdots E_n}$ with $\|\omega_{AB} - \gamma_{AB}\|_1 \leq \varepsilon$,$\gamma_{AB}$ 是 nR-bit private state
2. Normalization:$E_\text{sq}(A;B)_\gamma \geq nR$
3. Continuity:$E_\text{sq}(A;B)_\gamma \leq E_\text{sq}(A;B)_\omega + nf(\varepsilon)$
4. **Key step**(induction via Lemma 2 subadditivity):
   $$E_\text{sq}(A;B)_\omega \leq E_\text{sq}(\mathcal{N}) + E_\text{sq}(AB_n; B_1\ldots B_{n-1})_{\sigma^{(n)}}$$
5. 重复 (4) n-1 次(peeling-off argument):
   $$E_\text{sq}(A;B)_\omega \leq n E_\text{sq}(\mathcal{N})$$
6. 总结:$nR \leq n E_\text{sq}(\mathcal{N}) + n f(\varepsilon)$;除 n 取 n → ∞, ε → 0:$R \leq E_\text{sq}(\mathcal{N})$
7. sup over protocols: $P_2(\mathcal{N}) \leq E_\text{sq}(\mathcal{N})$

**核心技巧**:Lemma 2 subadditivity — 允许把 n 个连续 channel uses 的 squashed entanglement 分解为 n 个独立 single-use 贡献的 sum.

### 4.3 Pure-loss channel specific bound(Eq. 1)

**Setup**(Fig. 2):Pure-loss channel $N_\eta$ modelled as beam-splitter mixing Alice's mode $\hat{a}$ with vacuum $\hat{e}$ to output $\hat{b} = \sqrt{\eta}\hat{a} + \sqrt{1-\eta}\hat{e}$. Eve 的环境由**另一个 pure-loss channel of transmittance $\eta_1$** squashed(Fig. 2 下半部).

**Bound derivation**(§Pure-loss optical channel):
- 对 TMSV-input (large photon number limit $N_S \to \infty$),$E_\text{sq}(N_\eta)$ 有闭式
- 关于 $\eta_1$ optimize:the function in Eq. 6 is symmetric + convex in $\eta_1$,minimum at $\eta_1 = 1/2$:
  $$g((1+\eta)N_S/2) - g((1-\eta)N_S/2)$$
  其中 $g(x) = (x+1)\log_2(x+1) - x\log_2 x$
- $N_S \to \infty$ 极限:$\log_2[(1+\eta)/(1-\eta)]$

**最终 bound**:
$$\boxed{P_2(N_\eta) \leq \log_2\frac{1+\eta}{1-\eta}}$$

**High-loss approximation**($\eta \ll 1$):
$$\log_2\frac{1+\eta}{1-\eta} = \log_2(1+\eta) - \log_2(1-\eta) \approx 2\log_2(e) \cdot \eta = \frac{2\eta}{\ln 2} \approx 2.88\,\eta$$

### 4.4 与 PLOB 2017 的对比

**同一 pure-loss channel**:

| 形式 | 上界(任意 η)| 高损耗 η ≪ 1 近似 |
|------|----------|--------------------|
| TGW 2014 (Eq. 1) | $\log_2\frac{1+\eta}{1-\eta}$ | $\frac{2\eta}{\ln 2} \approx 2.88\eta$ |
| PLOB 2017 | $-\log_2(1-\eta)$ | $\frac{\eta}{\ln 2} \approx 1.44\eta$ |

**PLOB is 2× tighter** at all η(可证明:$\log_2\frac{1+\eta}{1-\eta} > -\log_2(1-\eta)$ 因为 $\log_2(1+\eta) > 0$).

**为何 TGW 松了 2×?**:TGW 用 squashed entanglement,PLOB 用 REE;对 **distillable** channel(如 lossy),REE = $D_1$ = Coherent Info,严格比 $E_\text{sq}$ 紧。

### 4.5 与实际 QKD 下界的对比(TGW Fig. 3)

TGW §Discussion 比较三条线:
- **Squashed upper bound**(TGW Eq. 1):magenta
- **Reverse coherent info lower bound**(Devetak-Winter / Ma 2010):blue,$\log_2(1/(1-\eta))$
- **BB84 decoy 实测**:黑
- **CV-GG02**:orange

**关键观察**(§Discussion):在 $\eta \ll 1$ 极限,TGW 上界与 reverse-coherent-info 下界 ratio 约 $2\eta / (\eta/\ln 2) = 2/\ln 2 \approx 2.88$ — 因此 **TGW 下不存在 BB84 rate scaling 的改进空间**(即 η 标度已是 optimal)。

## 5. Methods(§Methods 技术细节)

### 5.1 Weak converse + finite-n 修正(Eq. 8-9)

有限 channel use $n$ 时:
$$nR \leq n E_\text{sq}(\mathcal{N}) + 16\sqrt{\varepsilon}\log d + 4 h_2(2\sqrt{\varepsilon})$$

**强 converse**(论文未证明):如果成立,上界对任意 $\varepsilon$ 在 $n \to \infty$ 都会保持。TGW 说此为 "important open question"。

### 5.2 Infinite-dimensional considerations

Alice/Bob 在 initial 与 final step 是有限维,中间 processing 可以 infinite-dim(Supplementary Note 的 quantum data processing argument)。

### 5.3 Gaussian squashing 的合法性

Fig. 2 的 "Eve's squashing channel" 是 pure-loss channel of transmittance $\eta_1$. 这对 Gaussian input states 严格构成 valid squashing channel(Supplementary Note 2 + extremality of Gaussian states for conditional entropy 参考 [3, 4])。

对 non-Gaussian states → 通过 optimality of Gaussian states(Wolf-Giedke-Cirac 2006)延伸。

## 6. 对本项目的 Bearing

### 6.1 Point-to-point(Type A 协议) — PLOB 优于 TGW

对 Type A 协议(BB84, six-state, efficient BB84)在 lossy channel 下:
- **PLOB** 给更紧上界 $-\log_2(1-\eta)$
- TGW 松了 2×,**不推荐使用**

### 6.2 Relay-assisted(Type B 协议) — Pirandola 2019 优于 TGW

对 Type B 协议(MDI, TF, PM):
- **Pirandola 2019 N=1** 给 $-\log_2(1-\sqrt\eta)$
- TGW 未 extended 到 multi-hop network(只做 point-to-point)
- TGW **不适用** Type B

### 6.3 **TGW 的当前价值**:non-distillable 信道(amplitude damping / thermal-loss)

对 channels where PLOB bound 不是 tight(如 amplitude damping),TGW 的 squashed-E bound 可能更紧。具体:
- **Amplitude damping**(Eq. 49 in PLOB):$C(\mathcal{E}_\text{damp}) \leq H_2(1/2 - p/4) - H_2(1 - p/4)$ — 这其实是 squashed entanglement bound(TGW-style),tighter than PLOB's REE bound
- **Thermal-loss channel**:PLOB bound(Eq. 23)在高 n̄ 时松;squashed-E 可能更紧
- **Sub-Q3 §4.4 实施策略**:对 non-distillable 信道,使用 `min{E_R(ρ_E), E_sq(N)}` 作为上界

### 6.4 Sub-Q4 gap 归因 — TGW 视角补充

在 lossy/distillable 信道下:
- PLOB 是 tight → A 归因排除 ✓
- TGW 松 2× → 若用 TGW 作上界,会错误地归因 gap 给 "上界不紧"

**教训**:选择**最紧的** single-letter 上界(按信道类型)是 Sub-Q3 § 4.4 的核心任务,不能随便用 TGW。

## 7. Limitations

### 论文明示

- **Weak converse only**:$P_2 \leq E_\text{sq}(\mathcal{N})$ 在 $n \to \infty$, $\varepsilon \to 0$ 极限;strong converse 未证(open question §Discussion 末段)
- **Single-letter but possibly loose**:$E_\text{sq}$ 是 single-letter,但对 distillable channel 被 $D_1 \leq E_R$ 严格超过
- **Super-additivity of $P_2$ possible**:TGW §Discussion 末段 "unclear if product input states suffice to attain $P_2$"
- **Optical channel only**:TGW 主应用是 pure-loss($N_\eta$);其他信道(noisy, dephasing, amplitude damping)的具体 bound 需额外计算

### 本 memo 读者视角

- **2014 年 seminal work,后续被超越**:PLOB 2017 是 de facto standard for lossy channel
- **$E_\text{sq}(\mathcal{N})$ 数值计算很难**:squashing channel inf 需要优化;TGW 对 lossy 用 Gaussian squashing 闭式,但 non-Gaussian 情况需要 numerical
- **与 Pirandola 2019 兼容性**:squashed-E 满足 LOCC monotonicity,故 Pirandola teleportation stretching 框架也可适用于 $E_\text{sq}$ path — 但文献未系统化
