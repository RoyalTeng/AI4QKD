## 1. 一句话总结

**PLOB 为 point-to-point 量子信道给出了双向辅助容量($Q_2 = D_2 = K = P_2$)的 single-letter 上界 $E_R^\star(\mathcal{E})$,并通过 teleportation stretching + relative entropy of entanglement (REE) 的组合技术,为所有 teleportation-covariant channels(Gaussian、Pauli、erasure)得到闭合形式;最重要的应用是 lossy channel $C(\eta) = -\log_2(1-\eta)$,在 $\eta \ll 1$ 时退化为 $\simeq 1.44\,\eta$ bits/use,这就是**无中继 QKD 的最终率**(对 Alice-Bob 两点间的 point-to-point 信道成立,对含 untrusted relay 的 TF-QKD 拓扑不直接适用)。

## 3. 数学准备

### 3.1 Adaptive 协议(§Adaptive protocols, Fig. 1)

- Alice + Bob 有本地寄存器 $\mathbf{a}, \mathbf{b}$
- 协议结构:$\rho^0 \xrightarrow{\Lambda_0} \mathbf{a_0}\mathbf{b_0} \xrightarrow{\mathcal{E}} \mathbf{a_1}\mathbf{b_1} \xrightarrow{\Lambda_1} \cdots \xrightarrow{\mathcal{E}} \mathbf{a_n}\mathbf{b_n} \xrightarrow{\Lambda_n} \rho_{\mathbf{ab}}^n$
- $\Lambda_i$ 是 adaptive LOCC(双向 classical channel 任意,本地 operations 任意)
- 目标 state $\phi_n$ 与输出 $\rho_{\mathbf{ab}}^n$ 的 trace distance ≤ ε

- **容量定义**:$C(\mathcal{E}) = \sup_\mathcal{L} \lim_n R_n$(sup over all adaptive protocols)
- **四个 two-way 容量等价**(§Adaptive protocols):
  $P_2 = K \geq D_2 = Q_2$(private classical = secret key ≥ distillable entanglement = two-way quantum capacity)

### 3.2 Relative Entropy of Entanglement (REE)

对 bipartite state $\rho$:
$$E_R(\rho) := \inf_{\sigma_s \in \text{SEP}} S(\rho \| \sigma_s)$$

其中 $S(\rho \| \sigma) = \text{Tr}[\rho (\log_2 \rho - \log_2 \sigma)]$ 是 relative entropy, SEP = separable states.

**扩展到 asymptotic states**(Eq. 4):
$$E_R(\sigma) := \liminf_{\sigma_s^\mu, \mu \to \infty} S(\sigma^\mu \| \sigma_s^\mu)$$

**正则化**(Eq. 5):$E_R^\infty(\sigma) := \lim_n E_R(\sigma^{\otimes n})/n \leq E_R(\sigma)$

**Channel REE**(Eq. 6):$E_R(\mathcal{E}) := \sup_\rho E_R[\mathcal{I} \otimes \mathcal{E}(\rho)] \geq E_R(\rho_\mathcal{E})$,其中 $\rho_\mathcal{E}$ 是 Choi matrix.

### 3.3 Teleportation covariance

**定义(Eq. 9)**:$\mathcal{E}$ 是 teleportation-covariant iff 对任何 teleportation unitary $U$(Weyl-Heisenberg 群的生成元),存在 $V$ 使
$$\mathcal{E}(U \rho U^\dagger) = V \mathcal{E}(\rho) V^\dagger$$

**性质**:
- Pauli channels:tele-covariant + Weyl-covariant ✓
- Gaussian channels:tele-covariant + Weyl-covariant ✓
- Erasure channels:tele-covariant 但 **不是** Weyl-covariant(因为改变 Hilbert 空间维度)
- **Amplitude damping channel:不是 tele-covariant**(关键例外,需要 CV↔DV decomposition)

### 3.4 σ-stretchability + Choi-stretchability

**σ-stretchable**(Eq. 8):存在 trace-preserving LOCC $\mathcal{T}$ 使
$$\mathcal{E}(\rho) = \mathcal{T}(\rho \otimes \sigma)$$

**Choi-stretchable**:σ = ρ_E (Choi matrix);tele-covariant channels 天然 Choi-stretchable(Proposition 2, Fig. 3)

**Asymptotic simulation**(bosonic 必需):
$$(\mathcal{T}, \sigma) := \lim_\mu (\mathcal{T}^\mu, \sigma^\mu)$$
用 TMSV states $\Phi^\mu$ 作为有限能量 EPR approx,取 $\mu \to \infty$

## 4. 主要结果

### 4.1 Theorem 1 — General weak converse(Eq. 7)

**任何维度(finite/infinite),任何 channel**,两路容量被 REE 上界:
$$C(\mathcal{E}) \leq E_R^\star(\mathcal{E}) := \sup_\mathcal{L} \lim_n \frac{E_R(\rho_{\mathbf{ab}}^n)}{n}$$

这是 PLOB 框架的基础 — 不需要 channel 有特殊结构。

### 4.2 Lemma 3 — Stretching(Eq. 11)

**对 σ-stretchable channel**,任何 n-use adaptive protocol 的输出 state 可写成 block form:
$$\rho_{\mathbf{ab}}^n = \bar{\Lambda}(\sigma^{\otimes n})$$

其中 $\bar{\Lambda}$ 是 trace-preserving LOCC,$\sigma$ 是 resource state。

**证明技术**(§Methods "LOCC-averaging in teleportation stretching", Eq. 84-92):
1. 每次 channel use 被 $\mathcal{T}(\rho \otimes \sigma)$ 替换(stretching)
2. 所有 $\mathcal{T}$ 被 commute 到协议开头,所有 $\Lambda_i$ 被 collapse 成一个 $\bar{\Lambda}$
3. 平均 over all measurement outcomes $\mathbf{u}$ → trace-preserving

**关键点**:对 bosonic channels,stretching 是 asymptotic($\sigma = \rho_\mathcal{E} := \lim_\mu \rho_{\mathcal{E}}^\mu$)

### 4.3 Theorem 5 — One-shot REE bound(Eq. 15-16)

**对 σ-stretchable channel**:
$$C(\mathcal{E}) \leq E_R^\infty(\sigma) \leq E_R(\sigma)$$

**对 Choi-stretchable channel**(σ = ρ_E):
$$C(\mathcal{E}) \leq E_R^\infty(\rho_\mathcal{E}) \leq E_R(\rho_\mathcal{E}) = \Phi(\mathcal{E})$$

**定义**:$\Phi(\mathcal{E}) := E_R(\rho_\mathcal{E})$ = "entanglement flux" of channel

### 4.4 Distillable channels(Eq. 2 + Fig. 5 inner box)

**定义**:hashing inequality $D_1(\rho_\mathcal{E}) = E_R(\rho_\mathcal{E})$(lower bound 与 upper bound 重合)

**典型成员**:
- Lossy channel
- Quantum-limited amplifier
- Dephasing channel
- Erasure channel

**结论**:$C(\mathcal{E}) = \Phi(\mathcal{E}) = E_R(\rho_\mathcal{E})$ 精确等于 two-way 容量

## 5. Single-letter 容量公式

### 5.1 Lossy channel(Eq. 19 — PLOB 主产品)

**Transmittance η lossy channel**(beam splitter with vacuum environment):
$$\boxed{C(\eta) = D_2(\eta) = Q_2(\eta) = K(\eta) = -\log_2(1 - \eta)}$$

**高损耗 ($\eta \ll 1$) 近似**(Eq. 20):
$$C(\eta) \simeq \frac{\eta}{\ln 2} \simeq 1.44\,\eta \text{ bits/channel use}$$

**物理含义**:
- 任何 point-to-point QKD 协议(BB84, MDI, decoy, CV)的终极率极限
- 只有 quantum repeater 能超过
- 实测差距:BB84 decoy ~ η/2 (2× below),MDI ~ η/(2e) (~5× below),CV 最接近 ~η/(4 ln 2) (~0.5× below)

### 5.2 Thermal-loss channel(Eq. 23-25)

**带 n̄ 热光子的 lossy**:
$$\Phi(\eta, \bar{n}) \leq -\log_2[(1-\eta)\eta^{\bar{n}}] - h(\bar{n})$$
其中 $h(x) = (x+1)\log_2(x+1) - x\log_2 x$.

Lower bound: $-\log_2(1-\eta) - h(\bar{n})$(reverse coherent info)

### 5.3 Quantum-limited amplifier(Eq. 28)

**Gain g amplifier**:
$$C(g) = D_2(g) = Q_2(g) = K(g) = -\log_2(1 - g^{-1})$$

### 5.4 Additive Gaussian channel(Eq. 29-30)

**Added noise ξ < 1**:
$$-\frac{1}{\ln 2} - \log_2 \xi \leq C(\xi) \leq \Phi(\xi) \leq \frac{\xi-1}{\ln 2} - \log_2 \xi$$

小 ξ 时上下界迅速重合。

### 5.5 Pauli channel(Eq. 34)

$\mathcal{P}(\rho) = p_0 \rho + p_1 X\rho X + p_2 Y\rho Y + p_3 Z\rho Z$,$\mathbf{p} = \{p_k\}$:

$$1 - H(\mathbf{p}) \leq C(\mathcal{P}) \leq \Phi(\mathcal{P}) = 1 - H_2(p_\text{max})$$

其中 $p_\text{max} = \max\{p_k\}$(仅当 $p_\text{max} \geq 1/2$ 时非零)。

### 5.6 Depolarizing channel(Eq. 36-37)

**一般 d 维,depolarizing prob p**:
$$\kappa(d, p) - f \log_2(d+1) \leq C(\mathcal{P}_\text{depol}) \leq \kappa(d, p)$$

其中 $\kappa(d, p) = \log_2 d - H_2(f) - f \log_2(d^2 - 1)$,$f = p(d^2 - 1)/d^2$.

**qubit d=2**:$\kappa(p) = 1 - H_2(3p/4)$

### 5.7 Dephasing channel(Eq. 39-41)

**Single-qubit dephasing prob p**:
$$C(\mathcal{P}_\text{deph}) = D_2 = Q_2 = K = 1 - H_2(p)$$

**推广到 qudit**(Eq. 40-41):对 $\mathcal{P}_\text{deph}(\rho) = \sum_{i=0}^{d-1} P_i Z^i \rho (Z^\dagger)^i$,$\mathbf{P} = \{P_i\}$:
$$C(\mathcal{P}_\text{deph}) = \log_2 d - H(\mathbf{P})$$

### 5.8 Erasure channel(Eq. 43-44)

**Single-qubit erasure prob p**:
$$C(\mathcal{E}_\text{erase}) = K = 1 - p$$

**d-维推广**:$K = (1-p) \log_2 d$

### 5.9 Amplitude damping channel(Eq. 47-49)

**damping prob p**:
$$\max_u \{H_2(u) - H_2(up)\} \leq C(\mathcal{E}_\text{damp}) \leq \min\{1, -\log_2 p\}$$

更紧的上界基于 squashed entanglement:
$$C(\mathcal{E}_\text{damp}) \leq H_2\left(\frac{1}{2} - \frac{p}{4}\right) - H_2\left(1 - \frac{p}{4}\right)$$

## 6. 证明技术细节(§Methods)

### 6.1 Teleportation-covariance → Choi-stretchability(Proposition 2, Fig. 3)

**证明 sketch**:
1. Alice 制备 EPR pair $\Phi_{AA'}$
2. Bell detection 于 (input state, A) → teleport input to A'
3. Channel $\mathcal{E}$ 作用于 A' → B
4. Tele-covariance property: channel commutes with teleportation unitaries(up to $V_k$)
5. Bob apply 校正 $V_k^{-1}$ → 完成信道 simulation via Choi matrix $\rho_\mathcal{E}$

对 CV:需要 TMSV $\Phi^\mu$ + 有限能 Bell detection $\mathcal{B}^\mu$,取 $\mu \to \infty$ 极限

### 6.2 LOCC-averaging in teleportation stretching(Eq. 84-92)

**关键技术**:
- 每次 channel use 被 simulation $(\mathcal{T}, \sigma)$ 替换
- $\mathcal{T}^k$ 是 conditional LOCC with probability $p(k)$
- **Factorized probability** $p(\mathbf{k}) = \prod_i p(k_i)$(因为 simulation 对各 channel use 独立)
- 平均 over 所有 measurement outcomes:
$$\rho_{\mathbf{ab}}^n = \bar{\Lambda}(\sigma^{\otimes n}), \quad \bar{\Lambda}^{\mathcal{E}} = \sum_\mathbf{u} \Lambda_\mathbf{u}^{\mathcal{E}}$$

### 6.3 Bosonic stretching 的 asymptotic 论证(Eq. 93-106)

- Energy-unbounded Choi matrix 导致 simulation 必须 asymptotic
- $\lim_\mu \|\mathcal{I} \otimes \mathcal{E}(\rho) - \mathcal{I} \otimes \mathcal{E}^\mu(\rho)\| \to 0$
- 通过 bounded diamond norm $\|\mathcal{E} - \mathcal{E}^\mu\|_{\diamond N}$ 展开一致收敛
- 结论(Eq. 99):$\|\mathcal{E} - \mathcal{E}^\mu\|_{\diamond N} \xrightarrow{\mu} 0$ 对任何有限 N

### 6.4 One-shot REE bound 证明(Eq. 107)

关键链条:
$$E_R(\rho_{\mathbf{ab}}^n) \leq_{\text{LSC of S}} \inf_{\sigma_s^\mu} \liminf_\mu S[\bar{\Lambda}_\mu(\sigma^{\mu \otimes n}) \| \sigma_s^\mu] \leq_{\text{monotonicity}} \inf_{\sigma_s^\mu} \liminf_\mu S[\sigma^{\mu \otimes n} \| \bar{\Lambda}_\mu^{-1}(\sigma_s^\mu)] = E_R(\sigma^{\otimes n})$$

使用:
- REE 的 lower semi-continuity
- Relative entropy 的 trace-preserving LOCC monotonicity
- REE 的 definition 对 asymptotic states

## 7. 与其他上界的比较

### 7.1 TGW 2014 — Squashed entanglement 上界

**TGW bound**(lossy channel): $E_\text{sq}(\rho_\mathcal{E})$ — **not tight**(Fig. 7 dotted vs red)

$$E_\text{sq}(\eta) \leq -\log_2\frac{1-\eta}{1+\eta}$$

在 $\eta \ll 1$ 时:$E_\text{sq} \approx 2\eta / \ln 2 \approx 2.88\,\eta$,是 PLOB 的 2×。

### 7.2 Squashed amplitude damping bound(ref [59] in PLOB)

Fig. 8b 对 amplitude damping 使用的 squashed entanglement bound:
$$\mathcal{C}(\mathcal{E}_\text{damp}) \leq H_2(1/2 - p/4) - H_2(1 - p/4)$$

此 bound 在高 damping 好(PLOB own $-\log_2 p$ Eq. 47 在 p > 0.9 松)

### 7.3 Wilde-Tomamichel-Berta 2017

WTB 在 REE 基础上进一步扩展到 covariant channels with resource states;PLOB 先 post,技术路径平行而非严格继承

## 8. Sub-Q3 / Sub-Q4 Bearing

### 8.1 PLOB 对 "Alice-Bob 直接信道" 的覆盖

对 **point-to-point lossy QKD**(BB84 decoy, MDI-QKD 单 Alice 到单 Bob 信道):
- **上界**:$R \leq -\log_2(1 - \eta_{AB})$
- 已有 QKD 实现(BB84 decoy, CV)距此上界 ≤ 2×
- Phase 2 Sub-Q3 的 core benchmark

### 8.2 PLOB **不直接适用** TF-QKD / PM-QKD 拓扑(**重要**)

**关键**:PLOB Theorem 1 适用于 **单信道** $\mathcal{E}: A \to B$ with adaptive LOCC(即只有 Alice 和 Bob 两方)。**TF-QKD / PM-QKD 有第三方 Charlie(untrusted relay)**,拓扑不同 ⇒ PLOB 上界 $-\log_2(1-\eta_{AB})$ 不直接构成 TF-QKD 的 rate 限制。

- PM-QKD 在 Ma §V 明示达到 $\sqrt{\eta}$ 标度,超过 PLOB $\eta$ 标度
- 不矛盾:这是因为 Charlie 作为 untrusted 中间节点修改了 adaptive-protocol 定义,stretching reduction 不再适用

**对 Sub-Q3 的意义**:
- PLOB 是 **direct-link** 上界,**不是** TF-QKD / 中继辅助 QKD 的上界
- 中继辅助(包括 TF)的正确上界在 **Pirandola 2019**(end-to-end capacities of quantum networks)
- TF-QKD 应与 **single-repeater bound** $-\log_2(1 - \sqrt{\eta})$(Pirandola 2019,Ma §VI 引用)对比,不是 PLOB

### 8.3 Sub-Q3 攻坚议程(基于本精读推导)

1. **PLOB direct-link** benchmark:BB84 decoy / MDI-QKD 的 Sub-Q3 gap ≤ 2×(容易做)
2. **Pirandola 2019 relay-assisted**:TF-QKD / PM-QKD 的真实上界是 single-repeater $-\log_2(1-\sqrt{\eta})$;Ma 承认"still far away"— 这是 gap 数量刻画的核心对象
3. **拓扑适用性 lemma**(Sub-Q3 §4.3 明列):必须证明 PLOB 在 MS-EB framework 下的正确映射,避免把 direct-link 上界误用到 relay 拓扑

### 8.4 Sub-Q4 gap 归因启示

对 Sub-Q4 的 A/B/C 分析:
- **A 上界松**:PLOB 本身是 tight 对 lossy/dephasing/erasure(因为 distillable);对 amplitude damping 仍有 gap(squashed 更紧)
- **B 下界松**:这是 PM-QKD 的主要位置(~10× gap 见 §7.5 实测)
- **C 协议未优**:PM-QKD 用 μ=0.15 固定,未 per-distance 优化;F6 §7.5c 提供 grid search

## 9. Limitations(论文 + 本 memo 读者视角)

### 论文明示

- **双方辅助 only**:PLOB 不覆盖多方场景(multipartite capacity);Pirandola 2019 推广
- **Choi-stretchable 覆盖不完整**:Amplitude damping 不是 Choi-stretchable(但可经 CV↔DV decomposition 处理);non-Gaussian non-Pauli 信道需额外工作
- **Asymptotic 对 bosonic**:TMSV $\Phi^\mu$ 取 $\mu \to \infty$;有限能量修正在 §Supp Notes
- **相对熵 regularization**:$E_R^\infty = \lim_n E_R(\sigma^{\otimes n})/n$ 的计算对 non-product $\sigma^{\otimes n}$ 可能不易 — PLOB 在 distillable class 通过 $D_1 = E_R$ 绕过

### 本 memo 读者(本项目视角)

- **MS-EB 框架映射**:PLOB 使用 general CPTP channel + adaptive LOCC;我们的 MS-EB 是 $(\mathcal{P}, \mathcal{E}, \mathcal{A}, \mathcal{T}, \mathcal{K})$ 五元组 — 映射不是直接的。Sub-Q3 §4.3 明确要求"拓扑适用性 lemma"
- **TF-QKD Charlie 处理**:Charlie 不是简单的 "Alice-Bob 中间信道",而是独立 adversarial 节点 ⇒ 需在 MS-EB formulation 下明确 Charlie 属于 $\mathcal{E}$(不是第三方) — 否则 PLOB stretching 不适用
- **Single-letter vs multi-letter**:Theorem 1 是 multi-letter;Theorem 5 把它 reduce 到 single-letter 的条件是 σ-stretchability,不是所有 channel 都满足
