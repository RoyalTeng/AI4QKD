## 1. 一句话总结

CML 2016 把 Devetak-Winter 公式 $K = H(Z_A|E) - H(Z_A|Z_B)$ 里的关键未知量 $H(Z_A|E)$,通过**恒等式**(Coles 2011/2012 PRA)化为 $D(\rho_{AB} \| \mathcal{Z}_A(\rho_{AB}))$(relative entropy to pinched state),然后在观测约束集 $C = \{\rho : \text{Tr}(\Gamma_k \rho) = \gamma_k\}$ 上做 SDP min;dual 化后用 Golden-Thompson 给单步下界(Eq. 8),首次把 QKD key rate 变成**任意 unstructured 协议可跑**的数值优化。

**"Unstructured" 的含义**:论文强调对 **缺少对称性** 的协议(device-imperfect BB84 / B92 / MDI / 任意两角度)均适用。对称 BB84 只是特例。

## 2. 核心数学 —— 与 WLC v0.4 §5 桥接的对应

### 2.1 Devetak-Winter(Eq. 1)

$$K = H(Z_A|E)_\rho - H(Z_A|Z_B)_\rho\qquad\text{(bit / signal)}$$

$Z_A$ = Alice key-map POVM(output classical);$Z_B$ = Bob 对应测量;$E$ = Eve(purification)。

### 2.2 Primal 优化(Eq. 7)

$$K = \min_{\rho_{AB} \in C} [H(Z_A|E) - H(Z_A|Z_B)],\quad C = \{\rho : \text{Tr}(\Gamma_i \rho) = \gamma_i\}$$

**变量维度**:$d_A^2 d_B^2$。BB84 是 $4 \times 4$ = 16 维参数。

### 2.3 核心 pinching 恒等式(**Eq. 40**,引自 Coles 2011/2012 PRA)

$$\boxed{H(Z_A|E)_\rho = D\!\left(\rho_{AB} \,\Big\|\, \sum_j Z_A^j \rho_{AB} Z_A^j\right)}\qquad\text{[bit,$\log_2$]}$$

这是**CML 论文的核心身份**,也是 WLC 2018 Eq. 53 的同一身份的另一种表述(WLC 多加了一个 $\mathcal{G}$ map 包装 post-selection)。

**与 WLC 2018 的对应**(v0.4 §5.2 已核对):
- CML:$H(Z_A|E)_\rho = D(\rho \| \mathcal{Z}_A(\rho))$
- WLC:$p_\text{pass} \cdot H(Z^R|E\widetilde A\widetilde B)_{\rho^{(5)}} = p_\text{pass} \cdot D(\rho^{(4)} \| \rho^{(5)}) = D(\mathcal{G}(\rho_{AB}) \| \mathcal{Z}(\mathcal{G}(\rho_{AB})))$

WLC 把 $\mathcal{G}$ post-selection 合进 channel,CML 把它留在外面作为 $\mathcal{G}$ 独立步骤(Eq. 18 $\tilde\rho_{AB} = \mathcal{G}(\rho_{AB})/p_\text{pass}$)。**两者数学等价**。

### 2.4 Coherence Φ 表达(Eq. 42)

$$\Phi(\rho, \Pi) := D\!\left(\rho \,\Big\|\, \sum_j \Pi^j \rho \Pi^j\right)$$

Eq. 43:$\alpha := \min_{\rho_{AB} \in C} \Phi(\rho_{AB}, Z_A)$。

这是 CML 把 QKD key rate 连接到**量子 coherence** 理论(Baumgratz-Cramer-Plenio 2014)的桥梁。对项目本身不直接重要,但说明框架的数学普适性。

### 2.5 Dual 问题(Eq. 44-64,Golden-Thompson 引入松弛)

CML 把 primal rescale 为 $\hat\alpha := \alpha \ln 2 = \min \hat \Phi$(Eq. 44,消掉 ln 2 系数方便 Lagrangian)。

**Theorem 1**(Eq. 8):

$$K \geq \frac{\Theta}{\ln 2} - H(Z_A|Z_B)$$

$$\Theta := \max_{\vec\lambda} \left( -\left\| \sum_j Z_A^j R(\vec\lambda) Z_A^j \right\| - \vec\lambda \cdot \vec\gamma \right)\qquad\text{(Eq. 9)}$$

$$R(\vec\lambda) := \exp(-I - \vec\lambda \cdot \vec\Gamma)\qquad\text{(Eq. 10)}$$

**关键缺陷**:Eq. 60-62 用 Golden-Thompson $\text{Tr}(\exp(A+B)) \leq \text{Tr}(\exp A \exp B)$ 给 $\eta(\vec\lambda)$ 的下界,**引入松弛**。对高维 $d$ 或非对称协议,gap 可能显著。这是 WLC 2018 Thm 1 改进的直接原因(用 Fréchet + cutting-plane 替 Golden-Thompson)。

### 2.6 Θ/ln 2 里 /ln 2 的来源(v0.4 单位审计补充)

**注意**:CML Eq. 8 显式有 **/ln 2** 因子,但 CML 的 D 定义(Eq. 41)明确用 $\log_2$(bit 单位)。这个 /ln 2 **不是**"nat 转 bit",而是 CML 把原问题 rescale 为 $\hat\alpha = \alpha \ln 2$(Eq. 44)后,解出的 $\Theta$ 是"rescaled primal value",需要除 $\ln 2$ 返回原单位。

这一点与 WLC v0.4 §5.2 的 "log = $\log_2$" 结论一致。CML 的 /ln 2 是计算中间步骤 artifact,不改变最终 $K$ 的 bit 单位。

## 3. BB84 具体形式(Eq. 20-24)

### 3.1 Key-map POVM(Eq. 21)

$$Z_A = \{|0\rangle\langle 0|,\ |1\rangle\langle 1|\}$$

### 3.2 约束集(Eq. 22-24)

$$\langle \mathbb{1} \rangle = 1,\qquad \langle E_X \rangle = Q,\qquad \langle E_Z \rangle = Q$$

### 3.3 Error 算子显式形式(Eq. 25-26)

$$E_Z := |0\rangle\langle 0| \otimes |1\rangle\langle 1| + |1\rangle\langle 1| \otimes |0\rangle\langle 0|$$

$$E_X := |+\rangle\langle +| \otimes |-\rangle\langle -| + |-\rangle\langle -| \otimes |+\rangle\langle +|$$

**与项目 bb84-formulation.md v0.3 §8 的 Γ_qber_Z / Γ_qber_X 的对应**:
- $E_Z$ = $\Gamma_{\text{qber}\_Z}$(Z 基 "A 与 B 不同"投影子)
- $E_X$ = $\Gamma_{\text{qber}\_X}$(X 基 "A 与 B 不同"投影子)

**完全一致**,CML 给 bb84-formulation 的 Γ 构造独立佐证 ✓

### 3.4 理论参考率(Eq. 20)

$$K_\text{BB84}^\text{theory} = 1 - 2h(Q)\qquad\text{(bit / sift,$p_\text{pass}=1$ 的 asymmetric 基选择)}$$

**注意**:CML Eq. 20 是"**perfect sifting efficiency**" 假设下的 $K$(footnote 34 引 Lo-Chau-Ardehali 2005 efficient BB84),即 Alice Bob 把 Z 用作 key 的概率 → 1。对应的 **per sift**,不是 per signal。

项目 M1 benchmark 用的是 $K_\text{symmetric} = 0.5 \cdot (1 - 2h(Q))$(对称基选择,$p_\text{pass} = 0.5$),所以 CML 的 1 - 2h(Q) 和项目的 0.5·(1-2h(Q)) 是**同一协议不同基选择概率**下的量,数值差 2x。

## 4. Six-state 协议(Eq. 27-31)

### 4.1 三基约束

$$E_Y := |y_+\rangle\langle y_+| \otimes |y_+\rangle\langle y_+| + |y_-\rangle\langle y_-| \otimes |y_-\rangle\langle y_-|$$

其中 $|y_\pm\rangle = (|0\rangle \pm i|1\rangle)/\sqrt 2$。

$$\langle E_{XY}\rangle = Q,\qquad \langle E_Z\rangle = Q\quad(E_{XY} := (E_X + E_Y)/2)$$

### 4.2 对项目的影响

M1 scope 不含 six-state;留给 M4 如用户选择(REFACTORING_PLAN §5 scope)。但 CML 的 six-state 构造展示了框架对高维 / 三基的自然扩展,为 M4 做前置。

## 5. MDI-QKD 框架(Eq. 16-17 + Supplementary Note 1)

CML §MDI 给出的 $\rho_{ABM}$ tripartite 约束(Eq. 17)、marginal 约束 $\rho_{AB}$(Eq. 71)是 M2 MDI-QKD 的直接数学基础。本轮 Level 3 精读**不深入** Supplementary Note 1 具体推导,M2 实施期再看。

**主要接口**:
- $M$ 为 Charlie 公布的 Bell 基测量结果(classical register)
- $\rho_{ABM}$ 把 Eve + 不可信节点合并作 channel(Eq. 69-70)
- 没有明确讨论 decoy state(M3 需补)

## 6. 论文的两大贡献

1. **Numerical framework for unstructured protocols**(§Main contribution)
   - 从 $H(Z_A|E)$ 不可直接算 → 化为 $D(\rho \| \mathcal{Z}_A(\rho))$ → 在约束集 $C$ 上 min
   - BB84 / 6-state / MDI / B92 / arbitrary-angle 统一框架
   - Matlab 实现,可 run 常见协议

2. **Connection to coherence**(§Eq. 42-43)
   - QKD key rate = optimizing coherence(relative entropy of coherence)
   - 数学上对 resource theory of coherence(Baumgratz-Cramer-Plenio 2014)有反哺
