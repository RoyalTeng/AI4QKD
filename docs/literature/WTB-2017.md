## 1. 一句话总结

**WTB 2017 把 PLOB 的 weak converse 升级为 strong converse**:对任意 **teleportation-simulable** channel(包括 covariant channels, bosonic Gaussian, pure-loss, QL amplifier),relative entropy of entanglement $E_R(\mathcal{N})$ 是 strong converse rate for private communication — 即 **如果 rate 超过 $E_R(\mathcal{N})$,任何协议的 error 概率指数衰减到 1**(而 PLOB 只证明了 error → not → 0)。技术核心是 **meta-converse + privacy test** 组合,对 covariant channels 还给出 **second-order expansion**(有限 blocklength converse bounds)。

## 3. 技术基础(§2)

### 3.1 Private state framework(§2.4, HHHO05 / HHHO09)

**Bipartite private state**(Eq. 1.2, Def 4):
$$\gamma_{ABA'B'} = U_{ABA'B'}(\Phi_{AB} \otimes \theta_{A'B'}) U^\dagger_{ABA'B'}$$
- $\Phi_{AB}$ 是 $A, B$ 上 maximally entangled state
- $U_{ABA'B'}$ 是 "twisting unitary"(条件 phase based on A, B register values)
- $\theta_{A'B'}$ 是 arbitrary state on "shield" systems
- 整个 $\gamma$ state **包含 $\log K$ bits 的 secret key**

**关键等价性**:
- Tripartite picture(Eve explicit):$\gamma_{ABE} = \frac{1}{K}\sum_i |i\rangle\langle i|_A \otimes |i\rangle\langle i|_B \otimes \sigma_E$
- Bipartite picture(Eve purified into $A'B'$):$\gamma_{ABA'B'}$ 如上
- **两种等价用于 privacy 分析**

### 3.2 Smoothed relative entropy of entanglement

**Hypothesis testing relative entropy**(Def Eq. 4.1):
$$D_H^\varepsilon(\rho \| \sigma) := -\log \inf\{\text{Tr}(\Lambda \sigma) : 0 \leq \Lambda \leq I, \text{Tr}(\Lambda \rho) \geq 1 - \varepsilon\}$$

**Smoothed $E_R^\varepsilon$**(Eq. 4.3):
$$E_R^\varepsilon(A;B)_\rho := \inf_{\sigma \in \text{SEP}(A:B)} D_H^\varepsilon(\rho_{AB} \| \sigma_{AB})$$

**Channel extension**(Eq. 4.5):$E_R^\varepsilon(\mathcal{N}) := \sup_\psi E_R^\varepsilon(A;B)_{\mathcal{N}(\psi)}$

### 3.3 Teleportation-simulable channel(Prop 2, Eq. 2.12)

**Def**:Channel $\mathcal{N}_{A' \to B}$ is **teleportation-simulable** with associated state $\omega_{AB}$ if:
$$\mathcal{N}_{A' \to B}(\rho_{A'}) = \mathcal{T}_{AA'B \to B}(\rho_{A'} \otimes \omega_{AB})$$

**Proposition 2**:每个 **covariant** channel 是 teleportation-simulable with $\omega_{AB} = \mathcal{N}_{A' \to B}(\Phi_{AA'})$ (即 Choi matrix)。

**包括**:Pauli channels, Gaussian channels, dephasing, erasure(for DV),pure-loss, QL amplifier(for CV,asymptotic)

## 4. Meta-converse bound(§4)

### 4.1 Privacy test

**Definition 8**(Privacy test):对 private state $\gamma_{ABA'B'}$,定义 POVM
$$\{\Pi_{ABA'B'}, I - \Pi_{ABA'B'}\}, \quad \Pi_{ABA'B'} := U_{ABA'B'}(\Phi_{AB} \otimes I_{A'B'}) U^\dagger_{ABA'B'}$$

**Lemma 9(Eq. 4.7)**:ε-approximate private state $\rho_{ABA'B'}$ passes γ-privacy test with probability ≥ 1 - ε.

**Lemma 10(Eq. 4.13)**:separable $\sigma_{ABA'B'}$ passes γ-privacy test with probability ≤ 1/K.

**核心**:Privacy test 能区分 private(A, B 强关联 + uniform key)vs separable(A, B 弱关联)。

### 4.2 Meta-converse(Thm 11, Eq. 4.21)

**对任意 channel 和 CPPP(classical pre- and post-processing)-assisted protocol**:
$$\hat{P}_\mathcal{N}^\text{cppp}(1, \varepsilon) \leq E_R^\varepsilon(\mathcal{N})$$

**Proof idea**:用 privacy test 的 Lemma 9/10:
- $\rho$ 是 ε-approximate private state,passes test ≥ 1 - ε
- Any separable state passes test ≤ 2^{-P̂}
- 所以 $E_R^\varepsilon \geq \log K$ at least → $P \leq E_R^\varepsilon(\mathcal{N})$

**Generalization to n uses**(Eq. 4.33):
$$\hat{P}_\mathcal{N}^\text{cppp}(n, \varepsilon) \leq \frac{1}{n} E_R^\varepsilon(\mathcal{N}^{\otimes n})$$

**For tele-simulable**(Eq. 4.34):
$$\hat{P}_\mathcal{N}^\leftrightarrow(n, \varepsilon) \leq \frac{1}{n} E_R^\varepsilon(A^n; B^n)_{\omega^{\otimes n}}$$

**关键新贡献**:LOCC-assisted(↔)case 也受 CPPP bound 约束,via teleportation simulation reduction(§3.4)。

## 5. Strong converse(§5)

### 5.1 Strong converse property

**Def**(§5.1 Eq. 5.5):rate $r$ is strong converse if
$$\liminf_n P_n > r \Rightarrow \lim_n \varepsilon_n = 1$$

**Strong converse capacity** $P^\dagger(\mathcal{N}) := \inf\{r : r \text{ is strong converse rate}\}$. Always $P(\mathcal{N}) \leq P^\dagger(\mathcal{N})$.

**Strong converse property**:$P = P^\dagger$(no regime where both $P < r$ and $\varepsilon < 1$)。

### 5.2 Main result(Thm 26, strong converse via $E_R$)

**Thm**:For teleportation-simulable channel $\mathcal{N}$:
$$P_\leftrightarrow^\dagger(\mathcal{N}) \leq E_R(\mathcal{N})$$

**Implication for pure-loss** $N_\eta$:
$$P_\leftrightarrow^\dagger(N_\eta) \leq -\log_2(1 - \eta)$$
(**PLOB bound is strong converse**,not just weak)

**物理意义**:any protocol exceeding $-\log_2(1 - \eta)$ over pure-loss $N_\eta$ has error → 1 exponentially. The PLOB result was only $\varepsilon \not\to 0$; WTB strengthens to $\varepsilon \to 1$.

### 5.3 证明 sketch

1. Combine Eq. 4.34 meta-converse with tele-simulability:
$$\hat{P}^\leftrightarrow(n, \varepsilon) \leq \frac{1}{n} E_R^\varepsilon(\omega^{\otimes n})$$
2. 用 **quantum Stein lemma** 类型 argument:$E_R^\varepsilon(\omega^{\otimes n})/n \to E_R^\infty(\omega) = E_R(\omega)$ as $n \to \infty$, $\varepsilon$ bounded away from 1
3. 合并:$\hat{P}^\leftrightarrow(n, \varepsilon) \leq E_R(\omega) + o(1)$ for any $\varepsilon < 1$
4. Strong converse follows:$P_n > E_R(\omega) + \delta \Rightarrow \varepsilon_n \to 1$

## 6. Second-order expansion(§6)

**Motivation**:Finite blocklength refinement beyond asymptotic.

**For covariant channels**(Thm 47 etc. in §6):
$$\hat{P}_\mathcal{N}^\leftrightarrow(n, \varepsilon) \leq E_R(\mathcal{N}) + \sqrt{\frac{V(\mathcal{N}, \varepsilon)}{n}} \Phi^{-1}(\varepsilon) + O\!\left(\frac{\log n}{n}\right)$$

其中 $V$ 是 "relative entropy variance"(类似 Shannon 渠道 capacity 的 CLT 修正)。

**Connection to Kamin 2025 / GEAT**:第二阶项 $\sqrt{V/n} \Phi^{-1}(\varepsilon)$ 与 Kamin 2025 的 $c_1 \sqrt{n}$ structurally parallel — WTB/PLOB 是 upper bound,Kamin 是 protocol-specific finite-key achievable rate。

## 7. Specific channel characterizations(§7-8)

### 7.1 Qubit channels(§7)

- **Dephasing**:$P(\mathcal{P}_\text{deph}) = 1 - H_2(p)$,exact
- **Erasure**:$P(\mathcal{E}_\text{erase}) = 1 - p$,exact
- **Entanglement-breaking**:$P = 0$(trivially,no entanglement → no secret key)

### 7.2 Phase-insensitive bosonic channels(§8)

**Finite blocklength strong converse** for all pure-loss, QL amplifier, additive Gaussian noise:
- PLOB 的 asymptotic bound 实际上是 finite-blocklength strong converse
- 适用 two-way assisted unconstrained private capacity

## 8. 对本项目的 Bearing

### 8.1 对 PLOB / Pirandola 框架的加强

**WTB 的 contribution(相对 PLOB)**:
- **数学性质**:将 "weak converse" 升级为 "strong converse" — 严格更强
- **实际影响**:PLOB bound($-\log_2(1-\eta)$ for lossy)是 **不可避免** 的硬限制(strong converse 意义),不是 mere upper bound
- **Sub-Q4 归因**:如果某协议声称 rate > $-\log_2(1-\eta)$,该协议在足够大 n 下**必然失败**(ε → 1)— 不是 "接近失败" 而是 "exponentially fail"

### 8.2 对 Pirandola 2019 N=1 bound 的 extension

WTB 本身是 point-to-point,但 **其 meta-converse 技术** via tele-simulable 与 Pirandola 2019 network stretching 兼容:
- Pirandola 2019 的 chain bound $-\log_2(1-\sqrt{\eta})$ 同样 strong converse(因 tele-simulable 的 chain teleportation 也 tele-simulable)
- 故 **TF-QKD 超过 $-\log_2(1-\sqrt{\eta})$ 在大 n 下 exponentially 失败**

### 8.3 Finite blocklength bridge(connection to Kamin 2025)

**Key insight**:WTB second-order expansion 与 Kamin 2025 GEAT finite-key achievable rate **is a two-sided sandwich**:

$$R_\text{Kamin}(n, \varepsilon) \leq \hat{P}^\leftrightarrow(n, \varepsilon) \leq E_R(\mathcal{N}) + c_1/\sqrt{n}$$

这允许 **Phase 2 Sub-Q3 做 finite-blocklength gap 分析**(not just asymptotic):
- 在 $n = 10^{10}$, $\varepsilon = 10^{-8}$ 的实际 QKD 参数下,Kamin 2025 给 achievable rate $R_K$
- WTB Eq. 6.?? 给 converse bound $R_{WTB}$
- Gap $R_{WTB} - R_K$ 是有限样本下"还能改进多少"的量化

## 9. Limitations(论文明示 + 本 memo 视角)

### 论文明示

- **Tele-simulable constraint**:WTB strong converse 在 tele-simulable channels 成立;任意 channel 尚未完全 settled
- **Covariant channels only for 2nd-order**:有限 blocklength expansion 要求 group covariance,某些信道(amplitude damping)不满足
- **Open problem §9**:是否 $E_R$ 对任意 channel 都是 strong converse rate(非 tele-simulable)仍是开放问题

### 本 memo 读者视角

- **与 TGW 2014 squashed-E 的关系**:两者在 lossy 下 $E_R < E_\text{sq}$(PLOB 给的 REE 比 TGW 的 squashed 紧);WTB 证明 REE 强化为 strong converse — **squashed-E 的 strong converse 未被证明**
- **与 Pirandola 2019 network extension**:WTB 主证明是 point-to-point;将 strong converse 扩展到 network(multi-relay)需要 additional work(不在 WTB 主 theorem 范围)
- **Practical QKD 实现**:strong converse 概念对 "protocol 能否达到率 R" 问题至关重要,但对实际 finite-sample QKD 工程的直接影响较小(finite-size $\varepsilon$ corrections 通常 ~10⁻⁸,不是 "exponentially close to 1")

## 10. 对 Sub-Q3 §4.4 数值工具链的输入

### 10.1 公共 API 建议(Phase 2 §4.4 target)

```python
# qkdx/numerics/e_r_upper.py

def e_r_lossy_channel(eta: float) -> float:
    """PLOB Eq. 19 / WTB Thm 26 strong converse for pure-loss."""
    return -math.log2(1 - eta)

def e_r_chain_lossy(eta_total: float, N_repeaters: int) -> float:
    """Pirandola 2019 Eq. 9 extension — strong converse via WTB + tele-sim chain."""
    eta_link = eta_total ** (1.0 / (N_repeaters + 1))
    return -math.log2(1 - eta_link)

def e_r_second_order_covariant(
    e_r_asymp: float,  # E_R(N) asymptotic
    n: int,            # blocklength
    eps: float,        # error parameter
    relative_entropy_variance: float,  # V(N, ε) — need per-channel computation
) -> float:
    """WTB second-order converse bound for covariant channels."""
    from scipy.stats import norm
    correction = math.sqrt(relative_entropy_variance / n) * norm.ppf(eps)
    # Note: correction is negative for ε < 0.5 (tightens upper bound)
    return e_r_asymp + correction
```
