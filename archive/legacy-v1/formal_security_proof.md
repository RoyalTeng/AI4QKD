## 1. 形式化安全模型

### 1.1 系统模型

#### 协议参与者：
- **Alice**: 发送方A，拥有相干光源
- **Bob**: 发送方B，拥有相干光源  
- **Charlie**: 测量方，执行干涉测量
- **Eve**: 攻击者，拥有有限量子能力

#### 协议组件：
```
量子部分:
  Alice源(QSP) → 量子信道1 → 干涉仪(QG) → 探测器(QD)
  Bob源(QSP)   → 量子信道2 ↗

经典部分:
  探测器 → 经典信道 → Alice处理(CP) → 验证(CV) → 密钥提取(CK)
                     Bob处理(CP)   ↗

创新特征:
  干涉仪 → Alice处理 (控制信号连接)
```

### 1.2 攻击者模型

#### Eve的能力假设：
1. **量子能力**：
   - 可以截获、存储、重发量子态
   - 可以执行任意酉操作
   - 拥有完美量子存储器
   - **但不能破坏量子力学定律**

2. **经典能力**：
   - 可以监听经典信道
   - 可以延迟、修改经典消息
   - 可以执行计算上可行的经典攻击

3. **实施攻击能力**：
   - 可以执行侧信道攻击
   - 可以操纵实验设备
   - 但受限于实际物理约束

### 1.3 安全目标

#### 信息论安全：
对于任意多项式时间攻击者Eve，满足：
```
I(K; E) ≤ ε
```
其中：
- K: 最终共享密钥
- E: Eve拥有的所有信息
- ε: 可忽略的安全参数

#### 具体安全要求：
1. **保密性**: Eve对密钥的猜测优势可忽略
2. **完整性**: 协议检测到Eve存在的概率足够高
3. **认证性**: 通信方身份得到验证
4. **可用性**: 合法用户能成功建立密钥

## 2. 攻击抵抗性证明

### 2.1 光子数分裂攻击 (PNS) 抵抗性

#### 攻击描述：
Eve利用多光子态，保留一个光子进行测量，转发其余光子。

#### 协议防御机制：
1. **相干态光源**：Alice和Bob使用相干态而非单光子源
2. **干涉测量结构**：Charlie执行干涉测量，非直接探测
3. **相位编码**：信息编码在相位而非光子数上

#### 安全性证明：

**定理1**：在相干态和干涉测量下，PNS攻击的信息增益可忽略。

**证明**：
设相干态的平均光子数为μ，Eve截获的光子数为n。
1. 对于相干态，光子数分布为泊松分布：P(n) = e^{-μ} μ^n / n!
2. Eve需要区分不同相位编码的相干态
3. 在干涉测量中，信息体现在干涉图案而非单个光子
4. 即使Eve获得部分光子，相位信息仍然模糊

**结论**：协议对PNS攻击具有内在抵抗性。

### 2.2 截获重发攻击抵抗性

#### 攻击描述：
Eve截获量子态，测量后根据结果重发新态。

#### 协议防御机制：
1. **第三方测量结构**：Charlie执行测量，Alice和Bob不直接测量
2. **干涉测量不可克隆**：干涉图案难以完美复制
3. **控制信号连接**：干涉结果直接影响处理节点

#### 安全性证明：

**定理2**：在第三方干涉测量下，截获重发攻击的误码率显著增加。

**证明**：
设原始量子态为|ψ⟩，Eve测量后得到结果r，重发|φ_r⟩。
1. Charlie的干涉测量依赖于两个输入的量子态
2. Eve的测量破坏量子相干性
3. 重发态|φ_r⟩与原始态|ψ⟩的干涉图案不同
4. 这导致验证阶段检测到异常

误码率下界：
```
QBER ≥ 1 - F(ρ_ideal, ρ_attack) / 2
```
其中F为保真度，对于非完美重发，F < 1。

**结论**：协议能有效检测截获重发攻击。

### 2.3 时间位移攻击抵抗性

#### 攻击描述：
Eve通过时间延迟操纵探测器效率。

#### 协议防御机制：
1. **干涉时间敏感性**：干涉测量对时间同步要求高
2. **控制信号反馈**：干涉仪通过控制信号影响处理
3. **时间监控潜力**：可添加时间监控组件

#### 安全性分析：

**定理3**：干涉测量结构对时间攻击具有天然敏感性。

**证明**：
干涉仪的输出依赖于两个输入的相对相位：
```
I(θ) = I₀ cos²(Δφ/2)
```
其中Δφ = φ₁ - φ₂ + δ，δ为路径差引起的相位。

Eve的时间延迟Δt引入额外相位：
```
δ_Eve = ωΔt
```
这导致干涉图案偏移，容易被检测。

**结论**：协议对时间攻击有一定抵抗性，可进一步增强。

### 2.4 中间人攻击抵抗性

#### 攻击描述：
Eve冒充Charlie或操纵经典信道。

#### 当前协议状态：
⚠️ **脆弱点**：缺乏明确认证机制

#### 安全性增强方案：

**定理4**：添加认证机制后，协议可抵抗中间人攻击。

**证明框架**：
1. 在经典信道添加认证协议（如Wegman-Carter）
2. 使用预共享短认证密钥
3. 认证失败概率上界为2^{-l}，其中l为认证密钥长度
4. 结合隐私放大，最终密钥仍安全

**结论**：通过添加认证，协议可达到标准QKD的安全水平。

## 3. 安全参数计算

### 3.1 密钥率下界

基于GLLP框架，安全密钥率下界为：

```
R ≥ q { Q[1 - h(e)] - f(e)Q h(e) - Δ }
```

其中：
- q: 基匹配概率（对于本协议，q ≈ 0.5）
- Q: 增益（探测概率）
- e: 量子误码率(QBER)
- h(x): 二进制熵函数
- f(e): 纠错效率
- Δ: 有限长效应修正

### 3.2 对本协议的参数估计

#### 乐观估计（理想情况）：
- Q ≈ 10⁻⁵ (长距离相干态探测)
- e ≈ 0.01 (干涉测量精度)
- f(e) ≈ 1.2
- Δ ≈ 10/n (n为脉冲数)

**密钥率**: R ≈ 10⁻⁶ bits/pulse

#### 保守估计（实际约束）：
- Q ≈ 10⁻⁶
- e ≈ 0.05
- f(e) ≈ 1.5
- Δ ≈ 50/n

**密钥率**: R ≈ 10⁻⁸ bits/pulse

基于信道损耗模型：
